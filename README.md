## Featured project — Evil en Lucifer

I created **[Evil en Lucifer](https://evilenlucifervk.com)**, an independent digital-preservation and streaming platform dedicated to Visual Kei.

It combines software engineering, music technology and cultural preservation through:

- 📱 Android and web applications, with iOS development in progress.
- 🎧 Native audio playback, DSP, equalization, limiting, crossfade and media controls.
- 🔗 Flutter/Dart connected to C++ through JNI/FFI, using Oboe/AAudio and Android media APIs.
- ☁️ Cloudflare Workers/R2, Supabase/PostgreSQL, authentication, catalog services and CI/CD.
- 🗃️ A growing archive designed to make rare and historically important music accessible to new listeners.
